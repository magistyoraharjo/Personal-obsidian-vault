# PT Timboel Sales Order Fulfillment tab is the next ERPNext build

PT Timboel plans to build an ERPNext v15 Sales Order Fulfillment HTML tab. It should show ordered, delivered, reserved, draft-requested, submitted-requested, and unplanned quantities. It should create partial Stock Reservations and draft Material Requests, then refresh. The old `timboel_fulfillment_v0_1.zip` prototype is outdated because it creates Production Plans directly and lacks complete reservation and reconciliation handling.
