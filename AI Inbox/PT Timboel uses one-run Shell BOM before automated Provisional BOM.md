# PT Timboel uses one-run Shell BOM before automated Provisional BOM

PT Timboel accepts a system-generated submitted Shell BOM with one zero-cost placeholder material so the first Production Plan and Work Order can exist before real material quantities are known. This first run does not need useful material planning. Its submitted Manufacture Stock Entry must contain real consumed-material rows and immediately generate a real Provisional BOM draft for Production Head review. New Work Orders must stop using the Shell BOM after the Provisional BOM is approved.
