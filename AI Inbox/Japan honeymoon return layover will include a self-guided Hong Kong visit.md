# Japan honeymoon return layover will include a self-guided Hong Kong visit

The 12.5-hour Hong Kong return layover on 2 December 2026 is planned as a self-guided morning city visit. The intended route uses the first Airport Express, includes Victoria Harbour, the Star Ferry, breakfast, and either the Peak or Man Mo Temple, then returns to the airport around 11:00 for the 14:30 flight to Surabaya.
