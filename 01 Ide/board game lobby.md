	# Game plan

- a google form to create the lobby
- a google form to join a lobby
- one for requesting a game (this is where game list is important)
- make it dead simple to join, create lobby and make request
- protect host from empty lobby
- post a screen shot weekly, to the group chat. to announce that there is an open lobby
- make a lobby status, not everyone want to teach games so have that option
- automatically close lobby if its old
- all lobby is tied to a game, no lobby without games.

# Rules

## Lobby status definitions:
- Proposed : host pengen main, melihat dan cek interest, game wajib ada, no set place or time. cancelled after 2 weeks.
- Open : sudah ada minimal host join play dan 1 orang lain, cari tambah orang. waktu dan tempat sudah fix minimal antara 2 orang itu. menjadi confirmed atau cancelled setelah waktu lewat tergantung host. defaultnya menjadi cancelled
- Full : ndak yakin butuh, tapi ini i guess buat join waiting list. jumlah yang diminta host sudah penuh semua, waktu tempat sudah fix, tinggal main sakjane. tapi kalo ada yang mau WL bisa join disini.
- Complete : di mark game complete sama host. artinya lobby sudah selesai dan lewat. semua yang full automatically jadi complete h+1 kalo ndak ada konfirmasi.
 - Expired : ndak butuh. tidak ada beda dengan cancelled.

## Teaching Status definitions:
- teaching : salah satu dari confirmed player antara host atau 1 orang bisa teaching gamenya
- self teach : semua player di expect sudah nonton video teaching. host harus pasang link

## Requesting Status Definitions:
- bring 2 person minimium. this one is okay
- either one of them need to teach. this one also okay
- or want to be teached by a host, this one sucks. make it expire fast.

## Lobby Rule
- Every lobby open lobby need a min player, location and time
- every request lobby need a teacher or have to be marked self teach
- every lobby need a valid game
